# Generated API Documentation

Everything except this README is generated by `swaggo/swag`. Do not edit the
generated contents manually.

Regenerate the documentation from the Go annotations with:

```bash
make docs
```

The generated files are:

- `docs.go` registers the OpenAPI document with the Go application and is used
  by the Swagger UI at `/swagger/index.html`.
- `swagger.json` is the standalone OpenAPI JSON document.
- `swagger.yaml` is the standalone OpenAPI YAML document.

Update the handler annotations or response types in the Go source, then run
`make docs`. Do not edit the generated files directly.
